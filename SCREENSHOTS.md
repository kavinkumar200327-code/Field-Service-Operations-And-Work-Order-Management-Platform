# ServiSync Pro - Visual Application Showcase & Screenshots

This document presents annotated screenshots of the primary user interfaces, responsive layouts, role dashboards, and dynamic components across the **Field Service Operations & Work Order Management Platform**.

---

## 1. Authentication & Role Switcher
**File**: [`screenshots/01_login_page_demo_credentials.png`](./screenshots/01_login_page_demo_credentials.png)  
- **Description**: Enterprise login portal featuring **1-Click Demo Fill** capsules for all five evaluation roles (`Super Admin`, `Operations Manager`, `Dispatcher`, `Field Technician`, `Customer`).
- **Features**: JWT-based session provisioning, input validation, automatic redirection to role-specific default views.

---

## 2. Operations Executive Dashboard (Day Mode / Light Theme)
**File**: [`screenshots/02_operations_dashboard_day_mode.jpg`](./screenshots/02_operations_dashboard_day_mode.jpg)  
- **Description**: High-contrast, clean SaaS daylight theme (Linear/Stripe-inspired).
- **Features**: Real-time ticking clock (`04:09:02 pm`), Theme & Schedule dropdown menu, operational KPIs (Total Work Orders, Pending Requests, Technician Utilization, CSAT), volume completion trend graphs, and Active Status Mix.

## 3. Super Admin Command Center (Night Mode / Dark Theme)
**File**: [`screenshots/03_super_admin_dashboard_night_mode.jpg`](./screenshots/03_super_admin_dashboard_night_mode.jpg)

- **Features**: System governance HUD, microservices health indicators, rate matrix shortcuts, fleet supervision, and active perspective switcher.

## 4. Reports & Financial Analytics
**File**: [`screenshots/04_reports_and_financial_analytics.png`](./screenshots/04_reports_and_financial_analytics.png)

## 5. Interactive Status Mix & Detail Drill-Down
**File**: [`screenshots/05_active_status_mix_interactive_chart.png`](./screenshots/05_active_status_mix_interactive_chart.png)
